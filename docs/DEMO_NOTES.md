# Заметки к демонстрации

Этот файл отделяет технические детали и результаты проверок от короткого README.

## Сценарий показа

1. Запустить `npm run doctor`, затем `npm start`.
2. Показать выбор модели и список шести инструментов.
3. Создать чат с задачей без URL: агент начинает с поисковика, показывает `SEARCH` и действия в Chrome.
4. Открыть `/log` и `/history`, затем вернуться в чат и продолжить задачу.

## Как устроено

`CLI → Codex app-server → шесть browser tools → Playwright Core → видимый Chrome/Edge`.

Агент получает короткий снимок страницы с динамическими `@refs`, выбирает действие и после него снова наблюдает страницу. `complete` принимает только короткую точную цитату из свежего снимка. Чат хранит `threadId`, историю модели и отдельный профиль Chrome. Данные сессий остаются локальными в `chats/`, `profile/` и `runs/`.

При отсутствии точного адреса стартовая страница — Bing. Для явного URL предусмотрен прямой переход; запрос «на текущей странице» возвращает сохранённый адрес чата. Если поисковик недоступен, агент может выбрать другой. Адрес результата не нужно угадывать: правило агента требует открыть найденную ссылку.

## Технические решения и ограничения

- На Windows сначала выбирается CLI из установленного приложения Codex. Старый глобальный CLI `0.125.0` воспроизводимо падал на `service_tier = "default"`; CLI `0.155.0-alpha.16` с той же конфигурацией работает. Глобальная конфигурация пользователя не менялась.
- Зависимость `playwright-core` закреплена в `package-lock.json`. В репозитории нет `node_modules`, профилей браузера, чатов, трасс и секретов.
- Навигационные ссылки со словом «купить» в заголовке не требуют подтверждения. Явная пометка `risk=consequential` и действия удаления продолжают требовать его.
- Некоторые сайты ограничивают автоматизированный доступ или показывают CAPTCHA. Закрытый shadow DOM недоступен семантическому снимку. Агент ставит паузу, когда не может подтвердить результат.
- На динамическом каталоге Demoblaze один `@ref` устарел после перерисовки списка. Агент восстановился свежим снимком, но потерял около десяти секунд. Строгое доказательство результата также потребовало нескольких попыток; подсказка теперь просит короткую дословную цитату.
- `desktopBin` хранит путь к CLI установленного Codex, `startingUrl` выбирает первую страницу, `lines` содержит строки полного текста ошибки для CLI. Новых классов для этих изменений не вводилось.

## Управление сессией и компактные снимки

Ветка `feature/cli-session-controls`: многострочный промпт отправляется явной командой `/send`. Единственный новый класс `ConsoleInput` держит очередь строк, чтобы вставка целого блока не теряла данные, и обрабатывает `/stop` независимо от ожидания модели. `browsers` хранит открытый браузер каждого чата; `keepBrowser` сохраняет выбор галочки. `/browser` позволяет открыть окно до запуска агента и войти вручную. Полный выход из программы закрывает окна; выход из чата оставляет их открытыми при включённой галочке.

Остановка прекращает процесс Codex и блокирует следующие действия. Уже начатое действие браузера может завершиться или дождаться своего таймаута; оно не откатывается. Возврат в меню происходит после завершения текущего обработчика, чтобы старые действия не пересеклись с новой задачей. После остановки чат можно продолжить через сохранённый `threadId`.

Оптимизация сохраняет все метаданные элементов локально для проверок действий, а модели отправляет снимок без пустых полей и повторяющихся текста, контекста и ARIA-названия. Измерение одного снимка Books: **11 151 → 5 398 символов (−52%)**, без сокращения числа доступных refs. Это измерение размера, а не обещание ускорения модели на 52%. Также повторная задача не перезагружает уже открытую целевую страницу.

Проверка через PowerShell и меню на GPT-6 Luna: вставлен запрос из нескольких строк с пустой строкой; магазин Demo Web Shop → Books → Fiction, цена **24.00**, 3 вызова, 27,5 с. Следующий запуск остановлен через `/stop`, главное меню вернулось, Chrome остался открыт. Чат продолжен в том же окне: карточка Fiction, **Bestselling fiction**, цена **24.00**, 3 вызова, 17,3 с. Выключение `/keep` закрыло процессы только этого профиля. Большая вставка проверена отдельным тестом на 180 тысяч символов.

Архитектура остаётся в существующих модулях: ввод, меню, агент и браузер. Полная история чата сохранена; автоматическое урезание старых сообщений пока не добавлено, поскольку оно может потерять условия задачи. Ограничение: открытые окна потребляют память; их можно закрыть вручную либо выключить `/keep`.
