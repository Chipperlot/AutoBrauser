# AutoBrauser

[![CI](https://github.com/Chipperlot/AutoBrauser/actions/workflows/ci.yml/badge.svg)](https://github.com/Chipperlot/AutoBrauser/actions/workflows/ci.yml)

**Браузерный агент в терминале.** Вы ставите задачу обычным текстом, Codex выбирает действия, а Chrome показывает каждый шаг. Чаты, история моделей и профиль браузера сохраняются между запусками.

## Возможности

- **Видимый процесс:** в CLI отображаются модель, поисковый режим, вызовы инструментов, действия на странице и результат.
- **Поиск сайта:** если точный адрес не дан, агент начинает с поисковика и выбирает подходящий результат. Указанный URL открывается сразу.
- **Чаты с продолжением:** у каждого чата отдельные история, модель, сессия Codex и профиль Chrome.
- **Выбор модели:** GPT-6 Sol/Luna и GPT-5.6 Sol/Luna из доступного каталога Codex.
- **Шесть инструментов:** открытие и чтение страницы, действия, вкладки, завершение с доказательством и пауза.

## Быстрый старт

Требуются **Windows**, **Node.js 24+**, установленный **Chrome или Edge** и вход в **Codex CLI**.

```powershell
git clone https://github.com/Chipperlot/AutoBrauser.git
cd AutoBrauser
npm ci
codex login
npm run doctor
npm start
```

В меню: **N** — новый чат, **M** — модели, **T** — инструменты, цифра — сохранённый чат. В чате доступны `/history`, `/model`, `/tools`, `/log` и `/back`.

Вставьте промпт целиком, включая переносы и пустые строки, затем введите **`/send` на отдельной строке**. `/cancel` отменяет ввод. Во время работы **`/stop` + Enter** или **Ctrl+C** останавливает агента и возвращает главное меню.

**`/keep`** переключает галочку «Оставлять Chrome открытым» для чата. При включённой галочке окно сохраняется после задачи и выхода в меню; можно войти в аккаунт вручную. **`/browser`** открывает или показывает окно этого чата. Следующая задача использует тот же браузер. При полном выходе из программы окна закрываются, профиль и последний адрес сохраняются.

Попробуйте задачу без адреса: `Найди официальный сайт Node.js и открой раздел Learn`. Для прямого перехода укажите URL: `Открой https://demowebshop.tricentis.com/ и найди книги`.

## Разовый запуск и проверки

```powershell
npm start -- --task "Найди официальный сайт Node.js и открой раздел Learn" --model gpt-6-luna
npm test
npm run test:browser
```

`npm start` без `--task` открывает меню. `npm run doctor` проверяет Node.js, Playwright Core, браузер, Codex CLI и авторизацию. Для нестандартной установки Chrome задайте `AUTOBRAUSER_CHROME`, для Codex CLI — `AUTOBRAUSER_CODEX`.

Программа использует установленный Chrome или Edge; браузеры Playwright не скачиваются. Локальные чаты, профили и трассы не добавляются в Git. Технические решения, результаты живых проверок и ограничения собраны в [одном файле](docs/DEMO_NOTES.md).
